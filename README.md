# Shopping Ads Solutions — landing page

Новая сборка страницы `SAS Control Room (6).html`. Оригинал и `SAS Control Room.md` не тронуты.
Контент и дизайн те же: исправлены ширина, адаптив, навигация и доступность.

## Структура

```
index.html            разметка, секции подписаны комментариями (1–13)
css/
  base.css            токены (цвета, шрифты, ширина контейнера), reset, кнопки, общие классы
  header.css          липкая шапка, меню «Chapters» / гамбургер, боковой рейл
  sections.css        все секции по порядку страницы, у каждой свои media-запросы
js/
  navigation.js       меню, текущая глава в шапке, рейл
  hero-network.js     анимация на canvas в первом экране
  sections.js         переключатели, карта, графики, таймлайн, форма
assets/
  logos/*.svg         логотипы клиентов (были вшиты в HTML как base64)
  team/*.jpg          фото команды
```

## Брейкпоинты

| Формат    | Ширина       | Что происходит |
|-----------|--------------|----------------|
| XL        | ≥ 1440px     | контейнер до 1440px; при ≥ 1800px появляется боковой рейл глав |
| L         | 1200–1439px  | десктоп |
| M         | 1024–1199px  | ноутбук: сетки ужимаются (факты 2 колонки, Labs 3 колонки) |
| Tablet    | 768–1023px   | всё в одну колонку, анимация героя сверху, таймлайн вертикальный |
| Mobile    | ≤ 767px      | гамбургер, CTA внутри меню, команда по 2 в ряд; доп. правки ≤ 479px |

## Обновление файлов

После правки CSS/JS поднимите `?v=` в `index.html`, чтобы браузеры не держали старую версию.
